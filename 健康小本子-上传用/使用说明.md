# 健康小本子 · 使用说明

## 第一步：打开

1. 打开微信，找到家人发给你的文件「我的健康小本子」
2. 点开，按提示用浏览器打开（安卓点「用其他应用打开」，苹果点右上角「···」选「在浏览器打开」）
3. 打开后建议点一次「添加到主屏幕」，以后在桌面就能直接打开

> 这个页面**不需要联网**，打开后即使没网也能用。

## 第二步：记一次血压

1. 量完血压，看屏幕上的三个数字
2. 点屏幕下方橙色按钮「＋ 马上记一次血压」
3. 依次填：高压（上面的大数）、低压（下面的数）、脉搏（可留空）
4. 点「保存这次记录」

看不清血压计屏幕时，点「📷 拍血压计屏幕，放大照着填」，拍张照片放大看。

## 第三步：看结果

- 顶部会显示这次的判断和一句提醒
- 「最近的变化」里能看到趋势，红点表示那次偏高了
- 「今天的药」可以打勾，记下有没有按时吃

## 给医生看

设置里点「📄 生成报告给医生看」，可以：
- 复制成文字，发微信给子女或医生
- 打印出来（需要先用浏览器打开）

## 重要提醒

- **每次测量前先坐 5 分钟**，不说话，胳膊放在桌上与心脏同高
- 建议**早晚各量一次**，坚持记录才有意义
- 页面里的提醒只是参考，**不能代替医生**。不舒服请及时就医或打 120
- 数据只存在这台手机上。微信清理缓存可能会清掉，**建议每月点一次「备份数据」**

## 怎么看数值（家庭自测标准）

| 数值 | 含义 |
|---|---|
| 低于 90/60 | 偏低 |
| 120/80 左右 | 正常 |
| 130/80 以上 | 正常高值，要留意 |
| **135/85 以上** | **偏高**（家里量的标准，医院是 140/90） |
| 160/100 以上 | 高 |
| 180/110 以上 | 明显偏高，休息后复测，仍高就联系医生 |

> 收缩压高、舒张压低（例如 150/55）在老年人中常见，说明血管偏硬，**不能因为低压不高就放心**，要带给医生看。
